## 翻译方法

1. 以扫描原页为转录依据，按竖排日文的阅读顺序保留段落、跨页关系和疑读标记。
2. 根据这部小说的声音组织中文：自然、通顺，保留形象、人物关系、话外之意及政治经济论述的层次。
3. AI 参与转录、初译、辅助复核与电子书制作；郁江保留中文表达、关键判断与最终定稿的决定权。详见 [AI_DISCLOSURE.md](AI_DISCLOSURE.md)。

## 简约消融实验

**问题：当前写作提示，相比一句“忠实、自然地翻译”，有没有可辨认的收益？**

选取景物、对话、议论三类片段，共 15 段、1,121 个日文字符；每类用两组提示各生成一次，共六份新译。两组使用相同模型、原文、上下文、术语和输出约束，仅替换写作提示。结果与局限见 [实验记录](experiments/prompt-ablation/README.md)。

实验比较初次生成的译文，不拿经过修订的成书作其中一组，也不据此声称整套翻译框架已获验证。
