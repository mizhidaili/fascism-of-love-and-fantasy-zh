# 写作提示消融：三类片段、六份新译

比较的是本书当前生产提示里的三段写作要求，而非 `literary-translate` 整个 Skill 或所有历史翻译规则。

| 条件 | 内容 |
| --- | --- |
| framework | 当前写作提示：意义、声音、形象、议论层次和中文节奏 |
| minimal | 一句“忠实、自然地译为简体中文” |
| 固定项 | 原文、前文、术语、段落输出约束、模型、推理强度与运行器 |
| 模型 | gpt-6-astra，high |
| 规模 | 3 类片段 × 2 组 × 1 次；15 段，1,121 日文字符（不含上下文） |

## 样本

| 类别 | 章节 | 上卷 PDF 页 / 印刷页 | 段落编号 |
| --- | --- | --- | --- |
| 景物 | 第 1 章 | 8 / 6 | V1-P0008-S001 至 S003 |
| 对话 | 第 5 章 | 43 / 41 | V1-P0043-S002 至 S010 |
| 议论 | 第 26 章 | 324 / 322 | V1-P0324-S001 至 S003 |

样本按文本类型在生成前选定，并核对了原页；这是目的性抽样。每组重新生成，不使用成书译文。一次成功后不重跑选优。失败尝试如有，单独保留。

## 提示与证据

实际提示由 [framework.txt](framework.txt) 或 [minimal.txt](minimal.txt)、共同的 [shared.txt](shared.txt)，再加相同的日文原文、上下文与术语 JSON 拼成。`shared.txt` 原样保留生产提示其余约束，其中部分条款在这三个样本中不会触发。

[protocol.json](protocol.json) 记录生成前冻结的方案、校验值与调用顺序；[results.json](results.json) 记录实际运行和原始输出校验值；[RESULTS.md](RESULTS.md) 给出对照观察。

完整输入和未经改写的六份原始结果保存在本地，另制作不显示组名的 A/B 阅读页。人工读者评分尚未填写。公开结果中的文字分析由助手完成，不是独立人工盲评。

## 能回答与不能回答的问题

可以观察在这些片段上写作提示改变了哪些具体表达。不能从每组一次生成分离随机波动，不能推广到全书，也不能验证转录、审核或所有历史提示的效果。输出完整、JSON 正确只是运行检查，不代表文学质量更高。
